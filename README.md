# Unofficial Translations: CRA Commission Guidance (C(2026) 5252)

This repository contains community-driven, unofficial translations of the European Commission's official guidance on the **Cyber Resilience Act (CRA)**. The original document was published on July 27, 2026, under reference **C(2026) 5252**.

The goal of this project is to make the Commission's interpretations—especially regarding software licensing, open-source compliance, and commercial activities—more accessible to developers and organizations worldwide.

## 🤝 How to Contribute

We welcome community support to improve the existing translation or add new languages!

### Improving the German Translation
1. Navigate to the `[./de/]` folder.
2. Open a Pull Request (PR) with your wording or formatting improvements.

### Adding a New Language
1. Create a new folder named after the ISO language code (e.g., `/fr/` for French, `/es/` for Spanish).
2. Translate the guidance document and add a localized readme inside that folder.
3. Update the table in this main `README.md` and submit a Pull Request.
